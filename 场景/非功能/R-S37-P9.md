# R-S37-P9 国际化未界定范围与出海目标

- **场景**：S37 国际化与时区　**标签**：[P9-范围失焦](../../知识库/缺陷标签.md)
- **验证**：多解实现验证通过（2026-10-20，N=3，6 组冲突性假设：国际化范围/语言集/切换机制/时区处理/数据层/本期达标线）

## 命中条件

**正向特征（须出现）**：

- **F1 国际化意图声明**："支持/需要/做 + 国际化/多语言/i18n/本地化/出海"类结构。
  - 例："系统**需要支持国际化**，方便后续出海" → F1 成立；"要**支持多语言**" → F1 成立。
- **F2 范围裸奔**：国际化到什么程度（仅文案 / +时区货币 / 全量本地化）、目标语言集、目标市场（出到哪个海）**全部未界定**；"后续/未来"类时间词无本期边界。

**反向特征（须全部不出现）**——出现任何一个即不命中：

- **B1 范围界定**：本期国际化范围的界定（"仅界面文案多语言，时区货币后续"/"全量含 RTL 与合规"）。
  - 例："本期**仅做文案多语言**，时区货币二期" → B1 出现。
- **B2 语言/市场清单**：目标语言或目标市场的指明（"中英双语"/"东南亚市场"）。
  - 例："支持**中英日韩**四种语言" → B2 出现。
- **B3 达标线定义**：本期做到什么程度算完成的可验收口径（"文案零硬编码，新增语言仅需资源包"）。
  - 例："验收标准：**新增语言只需增加资源文件**，无需改代码" → B3 出现。

### 判定

```
(F1 ∧ F2) ∧ ¬B1 ∧ ¬B2 ∧ ¬B3 → 命中 R-S37-P9
```

判定式读法：**左边**（要国际化，但做到哪一层、为什么市场没说）**同时右边**（范围、语言市场、达标线一个没出现）→ 命中。

### 判定过程示例

**例 1（命中）**：

> "系统需要支持国际化，方便后续出海。"

| 特征 | 结果 | 依据 |
|---|---|---|
| F1 | ✓ | "支持国际化，方便后续出海" |
| F2 | ✓ | 范围/市场全裸奔 |
| B1 | ✗ | 范围分层无 |
| B2 | ✗ | 语言市场无 |
| B3 | ✗ | 达标线无 |

→ **命中**：实证显示 6 组互斥——国际化范围（全量本地化含货币/合规/RTL vs 仅文案键值化+UTF-8 vs 仅保证可被机翻——海外用户分别看到本地货币+合规弹窗、英文界面但时间价格不变、生硬机翻）、语言集（按市场多语种 vs 固定中英 vs 动态任意语——选阿语时 A 视市场有精校版，B 直接无选项）、切换机制（区域自动检测+记忆 vs 仅设置页手动 vs 无入口依赖浏览器翻译——新海外用户首屏自动本地语言 vs 默认中文需自寻设置 vs 必须自己触发翻译）、时区（UTC 存储+本地渲染 vs 统一单一时区 vs 不处理——查同一订单时间，海外用户要不要心算时差）、数据层（分类/字典/UGC 多语言化+后台运营 vs 结构预留 vs 机翻连带——海外用户看到精校译文 vs"英文界面+中文内容"混杂 vs 每次刷新可能不一致）、达标线（具备多区域上线能力 vs 文案机制就绪 vs 插件可翻——同一句验收对应三种交付物：多币种演示 / 新增语言包演示 / 翻译截图）。

**例 2（不命中）**：

> "国际化：本期界面文案支持中英双语，按用户设置切换；验收标准为文案零硬编码、新增语言仅需资源文件；时区货币多语言内容等留待出海版本。"

B1、B2、B3 全部出现 → **不命中**。

## 说明

本规则检测国际化需求的**范围与目标失焦**，与产品类型无关（SaaS/电商/内容平台均适用）。缺口实质：国际化是一个**分层谱系**——文案多语言（薄）→ +时区/日期货币格式（中）→ +合规/RTL/数据层多语言（厚），每层成本差一个量级；"支持国际化"没有锚定层，三个实现分别落在薄中厚三档。"后续出海"加剧失焦："后续"暗示本期不必全做，但做到哪步没说——达标线的分歧使验收时一方演示多币种、一方演示新增语言包、一方演示翻译插件截图，三种交付物互不可替代。目标市场的缺失则是根本性的：出到东南亚与出到欧美，语言集、合规义务（GDPR vs PDPA）、排版（RTL）完全不同——**没有目标市场的国际化是无的放矢**。P9 在此与 S32（多端）同构：一个动词（支持/国际化）承载整个谱系的开放解释。

## 误报注意

1. **出海计划文档承载**："国际化范围见出海路线图（一期东南亚）"——B1/B2 以外部文档形式存在，不命中，需人工核对路线图覆盖数据层与合规；
2. **框架约束即范围**："用 i18next 管文案，其他不做"是显式最小决策——范围已圈定（仅文案），不命中（但建议确认目标市场无 RTL 等硬需求）；
3. **纯展示型多语言站点**："官网要能切换中英文"——范围自含（展示文案）、语言自含（中英），不适用本规则。

## 漏报注意

1. **语言有范围无机制**："支持中英文"出现 B2 但切换机制/时区/数据层仍开放——部分定义变体，按六维度核对；
2. **"多语言"窄义迷惑**：需求写"多语言"但实指"多种外语界面"，数据层内容多语言是否含仍开放——需按维度逐项核对而非被关键词遮蔽；
3. **时间词偷渡范围**："先做基础国际化"——"基础"与"后续"同样无边界，不构成 B1 的实质界定。
