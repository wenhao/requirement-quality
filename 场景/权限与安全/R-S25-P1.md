# R-S25-P1 数据隔离未定义归属模型与作用面

- **场景**：S25 数据权限/隔离　**标签**：[P1-不完整](../../知识库/无效需求标签.md)
- **验证**：多解实现验证通过（2026-10-20，N=3，6 组冲突性假设：归属定义/上级可见性/协作授权/离职归属/公共数据/操作面）

## 命中条件

**正向特征（须出现）**：

- **F1 隔离禁令声明**："xx 角色 + 只能/只能看到/仅可见 + 自己的 + 数据/记录/客户"类结构（"只能"句式的数据范围禁令）。
  - 例："**业务员只能看到自己的客户数据**" → F1 成立。
- **F2 归属定义缺席**："自己的"如何判定（创建的 / 被分配负责的 / 所属部门范围的）**未定义**，上级可见性、例外态（公共数据/协作）亦缺席。

**反向特征（须全部不出现）**——出现任何一个即不命中：

- **B1 归属判定定义**："自己的"判定口径（"创建的"/"被分配为负责人的"/"所在部门的"）。
  - 例："**被分配为负责人的客户**才算自己的" → B1 出现。
- **B2 角色例外说明**：上级/主管/协作方是否受此禁令约束的说明。
  - 例："**主管可看下属全部数据**" → B2 出现。
- **B3 例外态定义**：公共池/无人认领/交接期数据的归属与可见性。
  - 例："**无人认领客户进公共池**，全员可见可申领" → B3 出现。

### 判定

```
(F1 ∧ F2) ∧ ¬B1 ∧ ¬B2 ∧ ¬B3 → 命中 R-S25-P1
```

判定式读法：**左边**（一句"只能看自己的"，但"自己的"没定义）**同时右边**（归属口径、角色例外、例外态一个没提）→ 命中。

### 判定过程示例

**例 1（命中）**：

> "业务员只能看到自己的客户数据。"

| 特征 | 结果 | 依据 |
|---|---|---|
| F1 | ✓ | "只能看到自己的客户数据" |
| F2 | ✓ | "自己的"口径未定义 |
| B1 | ✗ | 创建/负责/部门全没说 |
| B2 | ✗ | 主管可见性无 |
| B3 | ✗ | 公共池/交接无 |

→ **命中**：实证显示 6 组互斥——归属定义（被分配负责的 vs 部门范围内 vs 自己创建的——小张创建客户后转给小王，A 下小王可见小张不可见，C 下相反，B 下整组都可见，同一页面三张列表）、上级可见性（默认不能需授权 vs 组织树天然可看 vs 主管无特殊逻辑——销售总监打开页面看到 2000 条 vs 3 条）、协作（临时授权+到期收回 vs 范围调整长期共享 vs 不支持）、离职归属（转移即失明 vs 移出组织树失明 vs 历史跟进记录仍残留可见）、公共池（全员可申领 vs 部门内可见 vs 对所有业务员不可见——新员工首日看到 500 条 vs 空白页）、操作面（全表面隔离 vs 统一 SDK 全覆盖 vs 仅列表过滤——按 ID 直查详情在 C 可越权打开完整资料）。

**例 2（不命中）**：

> "业务员只能看到自己的客户数据：'自己的'指被分配为负责人的客户；主管可看下属全部数据；无人认领客户进公共池全员可申领；列表/详情/搜索/导出全部隔离。"

B1、B2、B3（含操作面）全部出现 → **不命中**。

## 说明

本规则检测数据隔离类需求的**归属模型缺失**，与数据对象无关（客户/订单/工单/商机隔离均适用）。缺口实质："只能看自己的"是目标态禁令，禁令的可执行性完全取决于三个未定义项：归属判定（owner/creator/org-scope 三种模型是三个不同系统）、角色矩阵（主管是不是"业务员"、协作方算不算）、例外态（公共数据的所有权真空）。实证中最重的一组是操作面：仅过滤列表不过滤详情查询的实现直接产生**越权安全缺陷**——这不是偏好差异，是信息缺口转化为实现风险的直接证据。数据隔离需求往往以合规/安全为由提出，写作者容易误以为"只能看自己的"已是明确禁令，实则禁令之下的模型选择才是系统分叉点。

## 误报注意

1. **组织模型外部承载**："数据按部门树隔离，模型见组织架构文档"——B1–B3 由组织模型文档承载，不命中，需人工确认覆盖交接/公共态；
2. **单一用户无协作场景**：上下文表明无主管/协作/交接（如个人记账工具的多端同步）——B2/B3 天然消失，B1 仍需核对；
3. **明确的全局例外**："所有人可见所有数据，仅导出需权限"——范围已显式重定义，不命中本规则。

## 漏报注意

1. **归属半定义**："自己创建的"出现 B1 但主管/公共池/操作面未说——部分定义变体，逐要素核对；
2. **禁令口语化**："各人管各人的""谁建的谁看"——F1 词表需覆盖口语隔离表述（后者同时是 B1 弱出现，需综合判定）；
3. **正向表述的禁令**："业务员可查看全部自己负责的客户数据"——正向句式隐含隔离禁令，F1 需语义级识别"范围限定"意图。
