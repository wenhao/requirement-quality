# R-S26-P1 操作日志未定义记录范围与内容要素

- **场景**：S26 审计/日志　**标签**：[P1-不完整](../../知识库/缺陷标签.md)
- **验证**：多解实现验证通过（2026-10-20，N=3，6 组冲突性假设：关键操作范围/内容要素/可见性/留存期限/失败记录/证据效力）

## 命中条件

**正向特征（须出现）**：

- **F1 日志要求声明**："关键/重要/敏感 + 操作 + 要/需要/记录 + 日志/留痕/审计"类结构。
  - 例："**关键操作要记录日志**" → F1 成立；"重要操作**需要留痕**" → F1 成立。
- **F2 范围与要素缺席**："关键操作"指哪些（范围）、日志记什么（要素）、给谁看、存多久**全部缺席**。

**反向特征（须全部不出现）**——出现任何一个即不命中：

- **B1 记录范围界定**：哪些操作算"关键"的枚举或界定（删除/导出/权限变更/全部写操作）。
  - 例："**删除、导出、权限变更**记录日志" → B1 出现。
- **B2 内容要素定义**：记什么字段（谁/何时/做了什么之外——改前改后值/来源 IP/成败）。
  - 例："记录**操作人、时间、改前值和改后值**" → B2 出现。
- **B3 可见性/留存约定**：谁能查看日志、留存多久（管理员界面可查 / 留存 1 年）。
  - 例："管理员可在后台查询，**留存两年**" → B3 出现。

### 判定

```
(F1 ∧ F2) ∧ ¬B1 ∧ ¬B2 ∧ ¬B3 → 命中 R-S26-P1
```

判定式读法：**左边**（要求记日志，但记什么、记多细没说）**同时右边**（范围、要素、可见性留存一个没出现）→ 命中。

### 判定过程示例

**例 1（命中）**：

> "关键操作要记录日志。"

| 特征 | 结果 | 依据 |
|---|---|---|
| F1 | ✓ | "关键操作要记录日志" |
| F2 | ✓ | "关键"未界定，要素全无 |
| B1 | ✗ | 哪些操作无 |
| B2 | ✗ | 记什么字段无 |
| B3 | ✗ | 谁看/存多久无 |

→ **命中**：实证显示 6 组互斥——范围（全部写操作+敏感读 vs 仅删除/导出/权限变更 vs 全部 HTTP 请求——普通编辑在 A 留痕、B 无痕、C 只有一条无业务含义的 URL）、内容要素（含改前改后值可还原现场 vs 人话描述+成败 vs 仅 HTTP 三要素——"谁改了我的数据"，A 能答"从 X 改成 Y"，C 答不出动了什么）、可见性（独立审计权限双人授权 vs 管理后台可自助查 vs 无界面仅服务器 grep）、留存（永久 WORM ≥5 年 vs 1 年 vs 随日志滚动 14–30 天——半年后翻旧账，C 的日志已滚没）、失败记录（成败都记且区分未遂 vs 只记成功——反复尝试越权导出在 B 完全无痕）、证据效力（防篡改签名导出 vs CSV vs 无）。

**例 2（不命中）**：

> "关键操作要记录日志：记录删除、导出、权限变更；每条含操作人、时间、对象、改前改后值和成败；管理员后台可查，留存两年。"

B1、B2、B3 全部出现 → **不命中**。

## 说明

本规则检测审计类需求的**记录语义缺失**，与业务领域无关（交易/配置/内容审核日志均适用）。缺口实质：日志需求 = 范围（记什么操作）× 要素（记多细）× 消费（给谁看、存多久、算不算证据）。"关键操作"是自我指涉的模糊词——用什么标准判断"关键"本身就是要定义的东西，三个实现分别选择宁多勿漏、业务高敏、技术全量三种口径，审计能力天差地别。审计日志的特殊性在于**价值兑现滞后**：写需求时没人看它，出事（客诉/纠纷/监管检查/追责）时才发现"该记的没记"或"记的不能用"——留存 14 天的日志在半年后的纠纷中等于不存在。范围的自我指涉 + 兑现的滞后性，使该场景的缺口比一般功能需求更隐蔽。

## 误报注意

1. **合规框架指定**："日志按等保三级要求记录"——B1–B3 由等保条款承载（其已规定要素与留存），不命中，需人工核对落地范围；
2. **平台日志中间件**："接入统一审计平台"——要素与留存由平台承载，不命中，需确认平台覆盖本业务操作；
3. **开发调试日志**：上下文表明指技术日志（log level/链路追踪）而非业务审计——不同场景，不适用本规则。

## 漏报注意

1. **范围部分界定**："删除要记日志"——B1 弱出现但要素/留存仍开放，部分定义变体；
2. **要素部分界定**："记录谁在什么时候操作的"——B2 弱出现（3 要素）但改前改后值/成败缺失——能否还原现场是审计核心，需按要素核对而非有字即过；
3. **口语化**："干了啥都得留个痕"——F1 词表需覆盖口语留痕表述。
