# R-S39-P4 版本兼容隐含跨度与迁移语义假设

- **场景**：S39 部署与版本兼容　**标签**：[P4-隐含假设](../../知识库/缺陷标签.md)
- **验证**：多解实现验证通过（2026-10-20，N=3，5 组冲突性假设：旧版本跨度/兼容语义/失败处置/并行策略/回滚能力）

## 命中条件

**正向特征（须出现）**：

- **F1 版本兼容声明**："新版本 + 要/需要 + 兼容 + 旧版本/历史/存量 + 数据/数据格式"类结构。
  - 例："**新版本要兼容旧版本的数据**" → F1 成立；"升级后**存量数据**必须可用" → F1 成立。
- **F2 兼容语义裸奔**："旧版本"指哪个版本起（跨度）、"兼容"是只读还是迁移、不兼容数据怎么处置**全部未定义**——隐含假设读者与写者共享同一版本观。

**反向特征（须全部不出现）**——出现任何一个即不命中：

- **B1 版本跨度界定**：兼容到多旧（"仅上一版"/"近 3 个版本"/"有史以来"）。
  - 例："兼容**近两个大版本**的数据" → B1 出现。
- **B2 兼容语义定义**：只读兼容 / 自动迁移 / 双向回滚的说明。
  - 例："旧数据打开时**自动迁移升级**" → B2 出现。
- **B3 失败与并行处置**：迁移失败数据的处置、新旧版本并行期读写策略。
  - 例："迁移预检失败则**阻断发布**；灰度期**双写**新旧格式" → B3 出现。

### 判定

```
(F1 ∧ F2) ∧ ¬B1 ∧ ¬B2 ∧ ¬B3 → 命中 R-S39-P4
```

判定式读法：**左边**（要兼容旧数据，但旧到哪、怎么算兼容没说）**同时右边**（跨度、语义、失败并行处置一个没出现）→ 命中。

### 判定过程示例

**例 1（命中）**：

> "新版本要兼容旧版本的数据。"

| 特征 | 结果 | 依据 |
|---|---|---|
| F1 | ✓ | "新版本要兼容旧版本的数据" |
| F2 | ✓ | 跨度/语义全裸奔 |
| B1 | ✗ | 版本跨度无 |
| B2 | ✗ | 只读/迁移无 |
| B3 | ✗ | 失败/并行无 |

→ **命中**：实证显示 5 组互斥——旧版本跨度（有史以来 LTS 降级链 vs 仅上一版 N-1 vs 上线时活着的生产数据——2019 年导出的文件能否被打开，三案不同）、兼容语义（只读+自动原地升级 vs 惰性迁移触及才转 vs 仅 schema 不报错即达标——旧数据被打开后原地升级/按需转换/停留旧格式）、失败处置（预检全量校验阻断发布 vs 坏行隔离跳过其余上线 vs 先 ALTER 报错再说——同一份脏数据，用户面对"升级被拒绝"/"部分功能缺数据"/"上线后报错"三种命运）、并行策略（版本标记+双格式互读 vs 单向双写窗口 vs 停机窗口一次性切换——不停机滚动升级时成功/数据错乱/不允许此操作）、回滚能力（迁移可逆应用回退即数据回退 vs 不可逆回滚靠备份恢复且用户负责 vs 无回滚概念——新版本出严重 bug 能否一键装回旧版继续干活）。

**例 2（不命中）**：

> "新版本兼容近两个大版本数据：旧数据打开时自动迁移升级；迁移预检失败阻断发布；灰度期双写新旧格式，迁移可逆支持回滚。"

B1、B2、B3 全部出现 → **不命中**。

## 说明

本规则检测版本兼容类需求的**跨度与语义隐含假设**，与升级类型无关（SaaS 滚动升级/私有化交付/客户端 App 均适用）。缺口实质：版本兼容需求 = 跨度（旧到哪）× 语义（读到什么程度）× 处置（失败/并行/回滚）。"旧版本"三个字在写作者脑中有明确锚点（通常指"上一个生产版本"），但企业软件客户的版本分布是散点——私有化客户可能停留在 3 年前的版本，跨度假设一错，迁移矩阵全错。"兼容"的语义光谱同样宽：从"能读"到"自动升级"到"可回滚"，每档实现成本差一个量级。P4 在此的特殊性：这是**写作者与特定读者之间的私有共识**（团队知道客户版本分布），而非领域公共知识——新加入的实现者完全没有渠道获得该假设，冲突率天然最高。与 S43 的分界：S43 是老系统数据**搬入**新系统（一次性迁移），S39 是新版本**读得动**旧版本数据（版本兼容），前者是项目，后者是能力。

## 误报注意

1. **客户版本矩阵外部承载**："兼容版本范围见交付矩阵（V2.3+）"——B1 以外部文档存在，不命中，需核对矩阵含失败处置与回滚约定；
2. **单一版本环境**：上下文表明仅一个生产版本在运行（初创 SaaS）——"旧版本"锚点唯一，跨度无歧义，但仍需核对 B2/B3（迁移与并行语义）；
3. **迁移项目另行立项**："数据兼容由迁移专项处理，本条仅要求应用层兼容"——范围已显式切分，不命中本规则（专项走 S43）。

## 漏报注意

1. **跨度有语义无**："兼容上一版数据"——B1 出现但只读/迁移/回滚语义仍开放，部分定义变体；
2. **"平滑升级"迷惑词**："升级要平滑不停机"——只约束了并行策略（B3 的一个维度），跨度与迁移语义仍开放，需逐要素核对；
3. **存量数据泛指**："兼容存量数据"与"旧版本数据"同义——F1 词表需覆盖存量/历史/老数据等表述。
