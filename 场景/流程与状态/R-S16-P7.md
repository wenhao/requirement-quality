# R-S16-P7 撤销功能只定义成功路径

- **场景**：S16 异常/回退/撤销　**标签**：[P7-流程断点](../../知识库/缺陷标签.md)
- **验证**：多解实现验证通过（2026-10-20，N=3，7 组冲突性假设：可撤状态边界/不可撤反馈/被拒路径/下游回滚节奏/撤销中间态/反悔恢复/确认强度）

## 命中条件

**正向特征（须出现）**：

- **F1 撤销/回退类动作声明**："做一个 / 支持 / 可以 + 撤销 / 撤回 / 回退 / 取消 / 退回 / 关闭 + 实体名"类结构。
  - 例："**做一个**订单**撤销**功能，用户**可以撤销**自己的订单" → F1 成立。
- **F2 成功路径描述**：撤销成功的后果定义（"撤销成功后 xx 关闭/失效/还原"），是**单向 happy path**。
  - 例："**撤销成功后订单关闭**" → F2 成立。
- **F2b 异常/边界词出现**（与 F2 互斥，出现则 F2 不成立）：不允许 / 不可撤销 / 被拒 / 失败 / 审核 / 撤销中 / 恢复 / 反悔 / 回滚 / 已发货 / 已支付限制类条件词。

**反向特征（须全部不出现）**：

- **B1 可撤边界**：哪些状态/条件允许撤销的限定（"仅 xx 状态可撤销"、"已发货不可撤"）。
  - 例："**仅未支付订单可撤销**" → B1 出现。
- **B2 拒绝路径**：不可撤或撤销失败时的反馈与去向（置灰+原因 / 报错 / 转人工）。
  - 例："不可撤销时**按钮置灰并提示原因**" → B2 出现。
- **B3 下游回滚**：撤销对关联对象（资金/库存/优惠券/积分/下游单据）的处理说明。
  - 例："撤销后**释放占用库存并退回优惠券**" → B3 出现。

### 判定

```
(F1 ∧ F2 ∧ ¬B1 ∧ ¬B2 ∧ ¬B3) → 命中 R-S16-P7
```

判定式读法：**左边**（要撤销、只说了撤销成功后怎样）**同时右边**（可撤边界、拒绝路径、下游回滚一个没提）→ 命中。F2b 与 F2 互斥：出现任何异常/边界词说明需求已意识到分支，本规则不命中（可能命中更细规则）。

### 判定过程示例

**例 1（命中）**：

> "做一个订单撤销功能，用户可以撤销自己的订单，撤销成功后订单关闭。"

| 特征 | 结果 | 依据 |
|---|---|---|
| F1 | ✓ | "做一个订单撤销功能，可以撤销" |
| F2 | ✓ | "撤销成功后订单关闭"单向主干 |
| B1 | ✗ | 哪些订单能撤全无 |
| B2 | ✗ | 撤不了怎么办无 |
| B3 | ✗ | 库存/资金/券全无 |

→ **命中**：实证显示 7 组互斥——可撤边界（未支付+已付未发货 vs 全部未终态 vs 仅未支付）、不可撤反馈（置灰+原因 vs 报错提示 vs 隐藏入口）、被拒路径（风控转人工 vs 明确原因可重试 vs 笼统 toast）、下游回滚（异步回调 vs 补偿事务最终一致 vs 同步瞬时）、中间态（退款中 vs 撤销单流转 vs 无中间态）、反悔（终态不可恢复 vs 完成前可撤回 vs 不可恢复）、确认强度（金额+验证码 vs 强制填原因 vs 一键确认）。

**例 2（不命中）**：

> "订单撤销功能：仅未支付订单可撤销；不可撤销时按钮置灰并提示原因；撤销后释放库存、退回优惠券。"

B1、B2、B3 全部出现 → **不命中**。

## 说明

本规则检测撤销/回退类需求的**异常与副作用路径缺失**，与实体领域无关（订单/工单/审批/发布的撤销均适用）。缺口实质：撤销需求 = 可撤边界 × 拒绝路径 × 下游回滚 × 撤销过程建模 × 反悔机制。撤销天然是"逆向流程"——正向流程（下单、审批）沉淀的资产（资金、库存、优惠、通知）都要逐项回退，而逆向的每一步都无业务常识可依（退款同步还是异步？撤了能恢复吗？），全是纯决策空间。且撤销往往发生在用户情绪紧张的时刻（下错单了），行为差异感知最强。与 R-S14-P7 的分工：S14 管"新流程的异常分支缺失"（驳回/超时/转办），S16 管"逆向操作自身的完整链路缺失"（边界/拒绝/回滚）——撤销功能出现在 S14 的正向流程里时，就是本场景。

## 误报注意

1. **回滚规则外部引用**："撤销细则见退款/售后文档"——B3 以外部形式存在，需人工确认覆盖度；
2. **无副作用的撤销**：上下文表明操作对象无下游资产（如撤销一条未发送的草稿评论）——回滚维度天然消失，规则降级为只检 B1/B2；
3. **撤销即删除**："撤销后数据删除且明确不可恢复"——若边界与后果已明说，不命中。

## 漏报注意

1. **边界词出现但无定义**："已支付订单不可撤销"出现 B1 词但"能退吗、怎么退"未说——词出现打破反向特征，但退款路径缺失仍在，属"部分定义"变体，需语义级判定；
2. **口语化拒绝**："撤不了的告诉他一声就行"——B2 以口语弱形式存在，词表需覆盖；
3. **副作用散落**："撤销后库存要还"出现 B3 词但资金/券未提——部分回滚，需按资产类型逐项核对（库存/资金/优惠/通知/下游单据）。
