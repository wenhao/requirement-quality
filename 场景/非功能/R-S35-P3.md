# R-S35-P3 "简洁易用"类体验形容词无操作化定义

- **场景**：S35 易用性　**标签**：[P3-主观模糊](../../知识库/无效需求标签.md)
- **验证**：多解实现验证通过（2026-10-20，N=3，5 组冲突性假设：信息架构/导航层级/操作路径/新手引导/衡量主体）

## 命中条件

**正向特征（须出现）**：

- **F1 体验要求声明**："界面/交互/操作 + 要/需要 + 体验形容词并列（简洁/易用/美观/流畅/方便/好用/友好…两个及以上，或单个形容词但无任何限定）"类结构。
  - 例："**界面要简洁易用**，方便用户操作" → F1 成立；"交互要**自然流畅**" → F1 成立。
- **F2 形容词无操作化**：形容词无目标用户、无场景限定、无任何可操作的验收口径（步数上限/完成率/评审方式），纯形容词堆叠。

**反向特征（须全部不出现）**——出现任何一个即不命中：

- **B1 目标用户画像**：为谁易用的指明（"新手小白"/"专业运营"，用户画像约束）。
  - 例："面向**首次使用的老年用户**" → B1 出现。
- **B2 操作化指标**：可测量的验收标准（"核心任务 3 步内完成"/"新手任务完成率 ≥90%"）。
  - 例："下单流程**3 步以内**完成" → B2 出现。
- **B3 衡量方式**：谁来评、怎么评的约定（用户测试/团队评审/数据指标）。
  - 例："以**5 名真实用户测试全部独立完成**为验收" → B3 出现。

### 判定

```
(F1 ∧ F2) ∧ ¬B1 ∧ ¬B2 ∧ ¬B3 → 命中 R-S35-P3
```

判定式读法：**左边**（要求简洁易用，纯形容词）**同时右边**（用户画像、操作化指标、衡量方式一个没出现）→ 命中。

### 判定过程示例

**例 1（命中）**：

> "界面要简洁易用，方便用户操作。"

| 特征 | 结果 | 依据 |
|---|---|---|
| F1 | ✓ | "简洁易用，方便操作"形容词堆叠 |
| F2 | ✓ | 无任何操作化 |
| B1 | ✗ | 为谁易用无 |
| B2 | ✗ | 无步数/完成率指标 |
| B3 | ✗ | 谁评怎么评无 |

→ **命中**：实证显示 5 组互斥——信息架构（单任务聚焦页一屏一操作 vs 高密度多列工作台一屏尽收 vs 默认后台模板——用户打开产品看到三种互斥的界面结构）、导航层级（强制扁平 2 级超层砍功能 vs 3–4 级导航树+面包屑 vs 层级不设限——A 的实现甚至会因此少掉功能）、操作路径（3 步向导式牺牲批量 vs 批量+快捷键优先单任务可 5 步 vs 不优化步数——完成同一任务的点击数与批量能力直接可感知）、新手引导（首次分步引导浮层 vs 预置模板工作台 vs 空白空状态——新用户首屏三态互斥）、衡量主体（小白用户测试完成率 ≥90% vs 专业效率指标+团队评审 vs 无人评估——迭代方向为小白简化 vs 为专家加速 vs 不迭代）。

**例 2（不命中）**：

> "界面易用性：面向首次使用的中年运营人员，核心任务（建单、审核）5 步内完成；以 5 名目标用户独立完成任务测试为验收。"

B1、B2、B3 全部出现 → **不命中**。

## 说明

本规则检测易用性需求的**体验形容词无操作化**，与产品形态无关（C 端/B 端/工具类均适用）。缺口实质：易用性需求 = 目标用户 × 操作化指标 × 衡量方式。"简洁"与"易用"在 C 端（减法、聚焦、少即是多）与 B 端（密度、批量、专业加速）心智中是**反方向**的——同一句形容词，极简派交付聚焦页，效率派交付高密度工作台，两者都真诚地认为自己满足了"简洁易用"，而它们的界面结构互斥。P3 在此的破坏力比性能场景更强：性能好歹有客观时钟，易用连度量衡都没有——没有衡量主体时，"易用"最终由实现者的自我评价裁决。实证的隐性上游分歧更印证缺口：三人连目标设备（移动端 vs 桌面端）假设都不同。

## 误报注意

1. **设计规范承载**："界面遵循公司设计系统与可用性准则"——B1–B3 由规范与走查流程承载，不命中，需确认规范含可用性标准；
2. **无障碍合规引用**："满足 WCAG 2.1 AA"——B2/B3 由标准承载（含可测试的成功准则），不命中；
3. **明确的美学委托**："视觉风格交给设计团队全权"是显式授权决策——范围已移交，不命中本规则（但交互结构仍建议核对）。

## 漏报注意

1. **单一形容词**："界面要美观"——单个形容词同样适用（F1 的"两个及以上"是典型不是门槛，无任何限定即命中）；
2. **形容词带假对象**："方便用户操作"中"用户"是泛指裸名词——不构成 B1（画像），画像需有具体人群限定；
3. **指标藏在别处**："整体易用，其中下单 3 步完成"——B2 部分出现（单任务），其余任务仍开放，按任务粒度核对。
