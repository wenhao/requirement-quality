# R-S34-P3 "主流"等集合形容词无清单无验收口径

- **场景**：S34 兼容性与环境　**标签**：[P3-主观模糊](../../知识库/无效需求标签.md)
- **验证**：多解实现验证通过（2026-10-20，N=3，5 组冲突性假设：清单与下限/验收口径/不支持处置/技术约束/测试方式）

## 命中条件

**正向特征（须出现）**：

- **F1 兼容要求声明**："兼容/支持 + 集合形容词 + 环境名词"类结构（主流/常见/常用/大部分 + 浏览器/设备/操作系统/分辨率/数据库…）。
  - 例："系统需要**兼容主流浏览器**" → F1 成立；"支持**常见移动设备**" → F1 成立。
- **F2 集合形容词裸奔**："主流/常见"无清单（哪些）、无版本下限（到多旧）、无兼容判定标准（什么算兼容）。

**反向特征（须全部不出现）**——出现任何一个即不命中：

- **B1 环境清单**：具体环境枚举或可核对的引用（"Chrome/Edge/Safari 及版本"/"browserslist 配置"/"两年内市场占有率 >1%"）。
  - 例："兼容 **Chrome ≥90、Safari ≥14**" → B1 出现。
- **B2 版本下限**：明确的最旧支持版本（"近两年大版本"/"ES2018 语法基线"）。
  - 例："**近两年大版本**内可用" → B2 出现。
- **B3 判定标准**：兼容的验收口径（功能可用 / 像素级一致 / 优雅降级）。
  - 例："核心功能可用，**视觉差异可接受**" → B3 出现。

### 判定

```
(F1 ∧ F2) ∧ ¬B1 ∧ ¬B2 ∧ ¬B3 → 命中 R-S34-P3
```

判定式读法：**左边**（要兼容，但"主流"是什么没说）**同时右边**（清单、下限、判定标准一个没出现）→ 命中。

### 判定过程示例

**例 1（命中）**：

> "系统需要兼容主流浏览器。"

| 特征 | 结果 | 依据 |
|---|---|---|
| F1 | ✓ | "兼容主流浏览器" |
| F2 | ✓ | "主流"无清单无下限 |
| B1 | ✗ | 无清单 |
| B2 | ✗ | 无版本下限 |
| B3 | ✗ | 无判定标准 |

→ **命中**：实证显示 5 组互斥——清单与下限（IE11+国产双核+Chrome≥69 锁死 vs 常青最新两版+国产忽略 vs 不列清单脚手架默认——同一用户用 360 兼容模式打开：A 正常、B 白屏、C 凭运气）、验收口径（全功能可用像素可容忍 vs 核心链路通视觉可缺失 vs 我的 Chrome 能跑即算——同一台旧 Safari，三份裁决相反）、不支持处置（UA 检测引导升级页 vs 静默降级少功能 vs 白屏不管——IE11 用户分别看到引导页/悄悄少一半功能/白屏零反馈）、技术约束（禁用新特性全量转 ES5 vs ES2020+ 自由用 vs 零配置）、测试方式（真机+云测发布前拦截 vs 线上监控 vs 用户即测试）。

**例 2（不命中）**：

> "兼容 Chrome/Edge 近两年大版本与 Safari 14+：核心功能可用，视觉差异可接受，不支持的旧浏览器展示升级引导页。"

B1、B2、B3 全部出现 → **不命中**。

## 说明

本规则检测兼容类需求的**集合形容词模糊**，与目标环境无关（浏览器/设备/OS/数据库版本兼容均适用）。缺口实质：兼容需求 = 环境清单 × 版本下限 × 判定标准。"主流"在不同背景的开发者指代完全不同的集合——政企客户视角 IE11 与国产双核仍在列，互联网视角常青浏览器即全部，极简派则以脚手架默认为界；且清单的分裂直接派生验收与处置的连锁冲突（一个形容词的歧义放大为三套用户可直接感知的系统行为：能打开/少功能/白屏）。本规则是 S33 性能规则（"要快"）的同族：P3 在非功能场景的通用模式——**集合形容词**（主流/常见）与**程度形容词**（快/慢）同样不可验收，前者缺清单，后者缺数值。

## 误报注意

1. **配置文件承载清单**："兼容范围见 browserslist 配置"——B1 以工程配置形式存在，需人工确认配置与客户环境匹配；
2. **标准引用**："按公司前端兼容性基线执行"——B1/B2 由组织标准承载，不命中；
3. **单一明确环境**："跑在我们提供的指定设备上"——环境唯一无集合歧义，不适用本规则。

## 漏报注意

1. **清单有下限无标准**："支持 Chrome 和 Safari"——B1 弱出现但版本下限与判定标准（B2/B3）仍开放，部分定义变体；
2. **相对时间词**："近两年的浏览器"——B2 以相对时间出现，需核实锚点（从何时算两年）是否可执行；
3. **兼容动词变体**："适配主流机型""覆盖大部分设备"——F1 词表需覆盖适配/覆盖类动词。
