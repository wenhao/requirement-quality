# R-S38-P1 可配置需求未定义配置主体与生效范围

- **场景**：S38 可配置与可扩展　**标签**：[P1-不完整](../../知识库/无效需求标签.md)
- **验证**：多解实现验证通过（2026-10-20，N=3，6 组冲突性假设：配置主体/配置范围/生效范围/预设方案/持久化/兜底护栏）

## 命中条件

**正向特征（须出现）**：

- **F1 可配置意图声明**："xx + 要做成/需要/支持 + 可配置/可自定义/灵活配置"类结构。
  - 例："列表的展示字段**要做成可配置的**" → F1 成立；"审批流程**支持自定义配置**" → F1 成立。
- **F2 配置语义缺席**：谁来配（用户/管理员/开发）、配什么（显隐/顺序/字段级/流程级）、对谁生效（本人/全员/角色）**全部缺席**。

**反向特征（须全部不出现）**——出现任何一个即不命中：

- **B1 配置主体定义**：谁有配置权（"每个用户自己配"/"仅管理员配置"）。
  - 例："**管理员**统一配置列表模板" → B1 出现。
- **B2 配置范围界定**：可配置项的枚举（"字段显隐与顺序"/"含自定义字段"）。
  - 例："可配置**字段显隐、顺序和列宽**" → B2 出现。
- **B3 生效范围定义**：配置变更对谁生效（"仅本人视图"/"按角色模板全员生效"）。
  - 例："配置**仅对自己生效**" → B3 出现。

### 判定

```
(F1 ∧ F2) ∧ ¬B1 ∧ ¬B2 ∧ ¬B3 → 命中 R-S38-P1
```

判定式读法：**左边**（要做成可配置的，但谁配、配什么、对谁生效没说）**同时右边**（主体、范围、生效面一个没出现）→ 命中。

### 判定过程示例

**例 1（命中）**：

> "列表的展示字段要做成可配置的。"

| 特征 | 结果 | 依据 |
|---|---|---|
| F1 | ✓ | "要做成可配置的" |
| F2 | ✓ | 配置语义全缺席 |
| B1 | ✗ | 谁配无 |
| B2 | ✗ | 配什么无 |
| B3 | ✗ | 对谁生效无 |

→ **命中**：实证显示 6 组互斥——配置主体（每个用户自主 vs 仅管理员普通用户只读 vs 用户抽屉勾选——B 方案下普通用户界面上永远不存在配置入口）、配置范围（显隐+顺序+宽度+筛选器 vs 模板级+必显字段锁定 vs 仅显隐——用户能否拖列序调列宽：A 可以，C 永远不能）、生效范围（仅本人 vs 管理员一改全员/角色实时生效 vs 仅本人本机——B 中一次配置变更改变所有用户的列表，A/C 任何改动他人不可见）、预设方案（角色起手视图可再改 vs 行业模板强制下发 vs 无模板单一默认——新用户首屏三种形态）、持久化（服务端跨端同步 vs 配置中心版本化 vs localStorage 本机——换设备后 A 配置仍在，C 配置丢失）、兜底护栏（自助恢复默认+最少列校验 vs 管理员锁定+版本回滚 vs 无兜底清缓存重置——用户能否把列表配到关键列全隐藏：B 强制阻止，A/C 允许）。

**例 2（不命中）**：

> "列表字段可配置：每个用户可配置字段显隐与顺序，仅对自己生效，配置跨端同步；至少保留 1 列，可一键恢复默认。"

B1、B2、B3 全部出现 → **不命中**。

## 说明

本规则检测可配置类需求的**配置三要素缺失**，与配置对象无关（字段/流程/表单/看板可配置均适用）。缺口实质：可配置需求 = 配置主体 × 配置范围 × 生效范围——三要素分别决定**权力分配**（用户自主还是管理员治理，这是产品政治而非性能问题）、**能力边界**（显隐是薄配置，自定义字段/筛选器是厚配置）、**影响半径**（本人/角色/全员）。"做成可配置的"最常见的误解是把配置默认为"每个用户都能配一切"，而企业软件的主流实践恰恰是管理员治理模板——两种理解都合理且互斥。配置还是**长出来的需求**：第一版做薄（显隐）后续加厚（自定义字段）是常态，未定义范围时实现者只能押注一个厚度，押错方向则返工。与 S01 的分界：S01 是"列了东西没规则"（静态内容缺约束），S38 是"给了自由没边界"（动态配置缺治理）。

## 误报注意

1. **竞品参照**："配置能力对齐 xx 系统"——B1–B3 由参照产品承载，不命中，需人工确认参照对象的配置模型已知于双方；
2. **平台配置框架**："用 xx 低代码平台的字段配置组件"——三要素由平台默认模型承载，不命中，需确认平台模型匹配业务（尤其权限）；
3. **明确的全权配置**："管理员可以配置一切，具体配置项后续按需加"是显式决策——主体已定（管理员），范围留待运营，不命中（但建议记录决策）。

## 漏报注意

1. **主体有范围无**："管理员可以配置列表"——B1 出现但配置项/生效粒度开放，部分定义变体；
2. **"自定义"歧义词**："支持自定义列表"——"自定义"可能是配置（选列）也可能是扩展（自定义字段），F2 需先消歧再核对要素；
3. **配置入口暗示主体**："用户可以在设置里调字段"——B1 以交互描述弱出现，需识别后按三要素完整核对。
