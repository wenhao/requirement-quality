# R-S02-P5 数值限额未指明边界算子致边界值歧义

- **场景**：S02 字段级校验　**标签**：[P5-歧义表述](../../知识库/无效需求标签.md)
- **验证**：多解实现验证通过（2026-10-22，N=3，2 组冲突性假设均三向互斥：边界算子/超限处置；用户驱动定向验证，CAND-045）

## 命中条件

**正向特征（须出现）**：

- **F1 限额声明 + 裸阈值**：「数值对象 + 限制/限/额度/上限/封顶/最高 + 具体数值」类表述，只给阈值，未给比较关系。
  - 例："报销金额**限制 100 万**" → F1 成立；"单笔**额度 5000**" → F1 成立。
- **F2 可比数量语境**：约束对象为数值型可比较量（金额/数量/次数/人数/库存/容量），非文本长度（见误报注意 2）。
  - 例："金额/次数/单数" → F2 成立。

**反向特征（须全部不出现）**：

- **B1 显式算子词**：不超过 / 以内 / 小于 / 低于 / 少于 / 不得高于 / 最多 / 至多 /（含）/（不含）/ 含边界 等端点指明。
  - 例："**不超过** 100 万" → B1 出现；"100 万**（含）**" → B1 出现。
- **B2 显式处置语义**：超限**拦截 / 不可提交 / 报错**，或**自动截断 / 封顶改为上限值** 的明确处置条款。
  - 例："超出**不可提交并提示**" → B2 出现；"超出部分**自动截断**" → B2 出现。

### 判定

```
(F1 ∧ F2) ∧ ¬B1 ∧ ¬B2 → 命中 R-S02-P5
```

判定式读法：**左边**（给了限额和具体阈值，但比较关系与超限处置都没说）**同时右边**（显式算子词、处置条款一个没出现）→ 命中。

### 判定过程示例

**例 1（命中）**：

> "报销单新增：报销金额限制 100 万元。"

| 特征 | 结果 | 依据 |
|---|---|---|
| F1 | ✓ | "限制 100 万"，无算子 |
| F2 | ✓ | 金额，数值可比量 |
| B1 | ✗ | 无"不超过/小于/（含）"类端点词 |
| B2 | ✗ | 无拦截/截断处置条款 |

→ **命中**：实证显示恰好输入 1,000,000.00 元整时，三个系统一放行（读作 ≤，限额含边界）、一拦截（读作 <，限制即不得达到）、一放行但弹二次确认（把 100 万读作触发阈值）——同一笔合规报销单三种命运；输入 150 万元时，行内报错保留输入 / 键入即挡（输入框不允许超出）/ 静默截断为上限三案表单行为完全不同。

**例 2（不命中）**：

> "单笔报销金额不超过 100 万元（含），超出时行内提示'超出单笔限额'且不可提交。"

B1（"不超过"+"（含）"）、B2（超出拦截+提示）出现 → **不命中**。

## 说明

本规则检测数值类字段校验的**边界算子歧义**，与字段领域无关（金额/次数/库存/人数限额均适用）。缺口实质：限额约束 = 阈值 × **比较算子 × 超限处置**——阈值人人读得懂，算子人人读得不同。P5 口径与 R-S42-P5（S42 实证确立）同源：**欠约束即歧义**——"100 万"字面精确，但 < 与 ≤ 的差集恰好是 1,000,000.00 这一个值，而边界值用例（恰好填到上限）在报销、限额、库存场景高频出现，分歧 100% 用户可感知（同一笔合规单据一放一拦）。词形强度分级：**"限制"类动词形态双歧义**（算子 + 处置都不定）；**"上限/额度/封顶"类名词形态**算子歧义较弱（惯例偏含端点），歧义主要落在处置语义（拦截还是截断）——无 B1/B2 时两者均命中。中文惯例参考：不超过/以内/最多 → 含端点，小于/低于 → 不含端点，惯例词由 B1 承载，规则只检裸限额形态。场景分界：录入字段的直接数值校验归 S02（本规则）；计算后金额（合计/累计）的约束归 S42；"金额超 X 走特殊审批"的阈值路由归 S14/S15——算子歧义特征同构，场景按约束对象与用途归位。

## 误报注意

1. **行业惯例承载**：风控/支付限额有书面规范（如"限额均含端点"明文）——B1 由惯例承载，不命中，需人工确认惯例同时覆盖处置语义；
2. **文本长度限制**："标题限制 20 字"——输入框 maxlength 惯例即 ≤（第 20 字可正常输入）且用户键入即感知，歧义弱，降级不命中；
3. **阈值外置**："限额取运营后台配置项"——阈值与算子外置（S38 可配置），不命中，需人工确认配置定义含算子与处置。

## 漏报注意

1. **算子词被例外软化**："100 万以内（特殊情况可放宽）"——B1 出现但例外条款未定边界与放宽口径，需人工核对；
2. **阈值路由形态**："金额 100 万走总监审批"——非校验拦截而是审批路由，场景归 S14/S15，但恰好命中走谁审批的歧义同构，本规则特征可复用；
3. **累计型限额**："每日累计限额 100 万"——算子缺口之外叠加口径缺口（单笔还是累计、重置时点，属 P1），命中本规则的同时需补口径核对。
