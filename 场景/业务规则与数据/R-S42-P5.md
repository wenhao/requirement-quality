# R-S42-P5 计算规则未定舍入与运算路径致分位歧义

- **场景**：S42 计算与精度　**标签**：[P5-歧义表述](../../知识库/无效需求标签.md)
- **验证**：多解实现验证通过（2026-10-20，N=3，6 组冲突性假设：舍入规则/运算路径与时机/折扣层级/多行尾差/权威口径/精度载体）

## 命中条件

**正向特征（须出现）**：

- **F1 计算规则声明**："xx + 按 + A 乘/加/减 B（再/然后 + 运算）+ 自动计算/算出"类公式化表述，含两个及以上运算步骤或含折扣/税率/比例因子。
  - 例："订单金额**按商品价格乘以数量，再乘以折扣自动计算**" → F1 成立；"总价按单价加运费再乘税率计算" → F1 成立。
- **F2 计算语义缺席**：舍入规则（四舍五入/银行家/截断）、舍入时机（每步/末次）、比例因子的作用层级、多行合计的尾差归属**未出现**——公式有骨架无语义，一句可多种解读。

**反向特征（须全部不出现）**——出现任何一个即不命中：

- **B1 舍入规则**：舍入方式与时机的指明（"银行家舍入""每步保留 2 位"）。
  - 例："金额**四舍五入保留两位，仅在末次结算时舍入**" → B1 出现。
- **B2 运算路径定义**：运算顺序与中间量的精确定义（"先算折后单价落库再乘数量"）。
  - 例："**先乘数量后乘折扣**，中间不舍入" → B2 出现。
- **B3 尾差与口径**：多行分摊尾差归属、金额不一致时权威口径的约定。
  - 例："优惠按行分摊，**尾差由末行吸收**；金额以**支付层**为准" → B3 出现。

### 判定

```
(F1 ∧ F2) ∧ ¬B1 ∧ ¬B2 ∧ ¬B3 → 命中 R-S42-P5
```

判定式读法：**左边**（给了计算公式，但舍入、路径、尾差语义没说）**同时右边**（舍入规则、运算路径、尾差口径一个没出现）→ 命中。

### 判定过程示例

**例 1（命中）**：

> "订单金额按商品价格乘以数量，再乘以折扣自动计算。"

| 特征 | 结果 | 依据 |
|---|---|---|
| F1 | ✓ | "价格×数量×折扣自动计算"公式 |
| F2 | ✓ | 舍入/路径/尾差全无 |
| B1 | ✗ | 无舍入规则 |
| B2 | ✗ | 无路径定义 |
| B3 | ✗ | 无尾差口径 |

→ **命中**：实证显示 6 组互斥——舍入规则（银行家舍入 1.005→1.00 vs 四舍五入→1.01 vs toFixed 伪舍入事实截断——同一笔尾差订单三个系统三种总价，用户对比小票/发票差 1 分）、运算路径（原文顺序全精度末次舍入 vs 折后单价先落分再乘——同一单 2.55×3×95 折，B 端 ¥7.26、A/C 端 ¥7.27）、折扣层级（逐行作用 vs 订单总额需凑单 vs 改写折后单价——满 100 打折场景"多买一件才便宜"的体验完全不同）、多行尾差（入舍入损益科目 Σ行≠总额 vs 末行吸收 vs 不分摊——"明细加起来≠总价"直接引发扣错钱投诉）、权威口径（账务层"展示是 bug" vs 支付层回写 vs 展示层——多扣 1 分钱申诉三系统三样处理）、精度载体（浮点 double 出现 0.30000000000000004 长尾——用户在账单页直接看见）。

**例 2（不命中）**：

> "订单金额计算：先乘数量后乘折扣，全程 decimal 中间不舍入，末次银行家舍入保留 2 位；折扣作用于订单总额，优惠按行分摊尾差末行吸收；金额以支付层为准。"

B1、B2、B3 全部出现 → **不命中**。

## 说明

本规则检测计算类需求的**公式语义歧义**，与计算对象无关（金额/积分/税费/佣金计算均适用）。缺口实质：计算需求 = 公式骨架 × **舍入规则 × 运算路径 × 尾差归属 × 权威口径**——公式人人读得懂，语义人人读得不同。P5 的机制在此最典型："再乘以折扣"字面无歧义（顺序明确），但**欠约束即歧义**：舍入方式三种（尾差 1 分钱去向不同）、舍入时机两种（每步 vs 末次，路径重排后分位差异）、折扣层级三种（凑单体验完全不同）——同一句公式在三个实现中产出分位级（0.01 元）差异，金额类差异用户 100% 可感知（对账单、小票、发票摆在一起）。计算规则的歧义还有**累积效应**：单笔差 1 分看似无害，订单量放大后对账系统性地对不平，财务与客诉成本随量增长。

## 误报注意

1. **行业惯例强约束**：税费计算有法定规则（如"四舍五入到分"有明文）——B1 由法规承载，不命中，需确认惯例覆盖尾差与口径；
2. **整数域无舍入问题**：公式全程整数运算（积分数=次数×系数且系数为整数）——舍入维度天然消失，降级为只检路径与口径；
3. **展示层无对账场景**：内部估算类计算（"预估收益"仅供参考）——分位差异用户不可对账，降级为提示。

## 漏报注意

1. **舍入有词无规**："金额保留两位小数"——保留≠舍入规则（进位/舍位/看奇偶未说），B1 需完整舍入语义；
2. **公式藏在字段名里**："订单金额 = 单价×数量×折扣率"以等式出现——F1 需覆盖等式表述；
3. **多公式并存**：一条需求含多个计算（行金额+订单总额+优惠分摊）时，每个公式的 B1–B3 须分别核对，一个公式定义完整不代表其余不缺。
