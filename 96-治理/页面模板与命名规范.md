# 页面模板与命名规范

## 命名

| 类型 | 命名 | 披露层 |
|---|---|---|
| 空间索引 | `_index.md` | L1 |
| 域摘要 | `_domain-context.md` | L2 |
| 规则 | `规则-R-Sxx-Px.md` | L3 |
| 标签 / 场景体系 | `标签-*.md`、`场景-*.md` | L3 |
| 方法 / 路由 / 矩阵 | `方法-*.md`、`路由-*.md`、`矩阵-*.md` | L3 |
| 证据 | `证据-*.md` | L4 |
| 学习 | `方法论-*.md`、`模板-*.md` | L5 |

## 规则页必备字段

`type`、`id`、`title`、`summary`、`scenario`、`group`、`domain`、`label`、`triggers`、`disclosure_level`、`status`、`confidence`、`evidence`。

## 正文结构

摘要优先、细节居中、证据最后。规则页必须包含规则定位、命中条件、判定式、判定示例、说明、误报注意、漏报注意。
