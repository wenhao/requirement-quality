# R-S30-P4 系统对接隐含接口契约六要素

- **场景**：S30 数据同步/接口约定　**标签**：[P4-隐含假设](../../知识库/无效需求标签.md)
- **验证**：多解实现验证通过（2026-10-20，N=3，6 组冲突性假设：字段范围/触发时效/失败兜底/方向/历史范围/映射维护）

## 命中条件

**正向特征（须出现）**：

- **F1 对接意图声明**："和/与/对接/同步/打通 + 系统名（现有 xx / ERP / CRM / WMS…）+ 数据 + 动作（同步/对接/打通）"类结构。
  - 例："**和现有 ERP 系统对接**，订单数据**自动同步**到 ERP" → F1 成立。
- **F2 契约要素裸奔**：同步的关键契约要素——字段范围（同步什么）、触发时效（多快）、方向（单向/双向）、失败兜底、历史范围、映射维护方——**未以任何形式出现**，需求隐含假设"这些不用说对方也知道"。

**反向特征（须全部不出现）**——出现任何一个即不命中：

- **B1 字段/内容范围**：同步哪些数据（字段清单 / 主表明细 / 核心字段）的说明。
  - 例："同步**订单主表和明细、金额、状态**" → B1 出现。
- **B2 时效与触发**：实时推送 / 定时批量 / 对方来拉的说明。
  - 例："**下单后实时推送**" → B2 出现。
- **B3 失败与方向约定**：失败重试/对账兜底、单向还是双向的说明。
  - 例："失败自动重试并**告警**；ERP 发货状态**回传**" → B3 出现。

### 判定

```
(F1 ∧ F2) ∧ ¬B1 ∧ ¬B2 ∧ ¬B3 → 命中 R-S30-P4
```

判定式读法：**左边**（要对接同步，就一句）**同时右边**（同步什么、多快、单向双向、失败怎么办一个没说）→ 命中。

### 判定过程示例

**例 1（命中）**：

> "和现有 ERP 系统对接，订单数据自动同步到 ERP。"

| 特征 | 结果 | 依据 |
|---|---|---|
| F1 | ✓ | "和现有 ERP 对接…自动同步" |
| F2 | ✓ | 契约要素全裸奔 |
| B1 | ✗ | 字段范围无 |
| B2 | ✗ | "自动"≠时效定义 |
| B3 | ✗ | 失败/方向无 |

→ **命中**：实证显示 6 组互斥（3 组三方互斥 + 3 组两方对峙）——字段范围（全字段含明细 vs 核心字段后续迭代 vs 主表不含明细——ERP 侧能否看到商品行明细、按明细开票）、触发时效（下单即推秒级 vs 视 ERP 能力实时或轮询 vs 固定 5 分钟批量——库存扣减滞后窗口差一个数量级）、失败兜底（重试+死信+日终对账 vs 静默下轮补试 vs 仅记日志——长期静默漏单用户感知为"ERP 少单"）、方向（双向回传 vs 单向——业务系统订单状态会不会随 ERP 审核自动流转）、历史范围（存量初始化 vs 上线起增量——ERP 查不查得到历史订单）、映射维护方（ERP 主数据方维护 vs 集成方自助配置 vs 代码硬编码——新增商品后同步自动生效还是持续产出失败单）。

**例 2（不命中）**：

> "订单数据同步到 ERP：同步主表+明细+金额状态，下单后实时推送；失败重试 3 次后人工处理；ERP 发货状态回传更新本系统。"

B1、B2、B3 全部出现 → **不命中**。

## 说明

本规则检测系统对接类需求的**接口契约隐含假设**，与对接对象无关（ERP/CRM/WMS/自研老系统均适用）。缺口实质：数据同步契约 = 字段范围 × 触发时效 × 方向 × 失败兜底 × 历史范围 × 映射维护——六要素全部开放。P4 的机制在此最典型："现有 ERP"四个字承载了写作者脑中的全部上下文（哪套系统、什么版本、有什么接口、谁管主数据），但读者并不共享——三个实现者对"订单数据"给出三种字段集，对"自动"给出三种时效（秒级/轮询/5 分钟批），"自动"一词尤其危险：它把时效契约伪装成了已定义。契约要素的分歧是复合的：字段 × 时效 × 方向任一不同，对账逻辑、编码对照、异常处理全盘不同——这是"能用但永远对不平"类事故的根源。

## 误报注意

1. **契约文档外部承载**："接口契约见《xx 对接方案》附件"——六要素以外部文档存在，不命中，需人工确认文档覆盖全部六要素；
2. **成熟连接器**："用官方标准连接器同步"——字段/时效由连接器模板定义，不命中，需确认模板覆盖业务字段；
3. **对方主导的协议**："ERP 方已给出接口规范，我方适配"——契约由对方文档承载，不命中（但我方侧的失败兜底与历史范围仍需核对）。

## 漏报注意

1. **要素部分出现**："同步订单号和金额"出现 B1 但时效/方向/失败仍开放——部分定义变体，按六要素逐项核对；
2. **"自动"迷惑词**："自动同步""实时同步"——词面有时效意味但无定义（实时是什么秒级？谁触发？），不应直接判 B2，需核实有无具体机制说明；
3. **方向隐含在语序里**："同步到 ERP"隐含单向，但回传需求可能藏在业务期待中——方向判定需结合上下文业务闭环（ERP 状态要不要回到本系统）综合判定。
